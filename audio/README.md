# Аудио «朱»

Записи живых дикторов из открытой базы **audio-cmn** (Hugo Lopez, PLIDAM/INALCO): https://github.com/hugolpz/audio-cmn

* `s/` — слоги путунхуа с тонами, диктор **Chen Wang** (CC BY-SA);
* `w/` — слова, диктор **Yue Tan** (база Shtooka, CC BY-SA, http://packs.shtooka.net/cmn-caen-tan/readme.txt).

Обработка (tools/make_audio_pack.py): обрезка тишины, выравнивание громкости, MP3 48 кбит/с. Распространяется на тех же условиях — CC BY-SA 3.0/4.0, с указанием авторов.
