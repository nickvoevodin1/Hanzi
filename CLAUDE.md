## Цикл работы
```
npm install            # jsdom для тестов
python3 tools/build.py # src → app/index.html (+ node --check)
npm test               # 6 наборов, все должны быть ✅
npm run serve          # http://localhost:8080 (Service Worker работает только по http(s), не file://)
```
После ЛЮБОГО изменения, попадающего в app/: поднять `const CACHE='hanzi-vNN'` в `app/service-worker.js`
(сейчас **v14**), иначе установленное у пользователя приложение не обновится.
Сборка проверена: `build.py` воспроизводит текущий `app/index.html` байт-в-байт.

## Архитектура (один файл, без фреймворков)
- Роутер: `go(name, params)` → `State.route` → `render()`; экраны: home, browse, lesson/hsk/search (viewList),
  card, study, session, draw, settings, stats, radical.
- Хранилище: IndexedDB `hanzi-trainer` v1, ключи `cards`, `settings`, `meta` (фоллбэк — память).
- **Прогресс: `State.cards[w.s]`** — ключ = иероглифы слова (`keyOf(id)`), НЕ индекс массива. Не ломать:
  иначе прогресс съедет при добавлении слов. Старые числовые ключи мигрируют в `loadState`.
- SRS: FSRS-5, стандартные 19 весов (`const W=[0.40255,…]`), retention `settings.req`=0.90.
- Даты: только `dstr()`/`todayStr()` (локальное время). `toISOString` для дней НЕ использовать (баг UTC
  во Владивостоке уже чинили).
- Режимы (`modes`): mix, recog, choice, produce, pinyin, listen, recall, typehz, tones, dictate.
  Новое слово сначала показывается карточкой `qIntro`. Undo — `undoLast()`. Клавиши: Space/Enter, 1–4, Backspace.
- Порядок новых: уроки Кондрашевского по возрастанию → HSK по уровню → частотность. Лимит `settings.sessionCap`.
- Прописи: hanzi-writer 3.7.3 с cdnjs; графика черт офлайн из `hanzi-data.json` → `window.HZDATA`.
- Озвучка `Speech`: если есть `./audio/manifest.json` — MP3 `./audio/<текст>.mp3`, иначе Web Speech zh-CN.
- Темы: светлая «Бумага» (по умолчанию) / тёмная «Тушь» через `data-theme`; цвета — CSS-переменные в :root.
- Цель: `settings.goal={on,date:'2026-09-18',lesson:20}`, `goalInfo()`, фазы learn/consolidate/over/done.
- Ключи: `RADS` (214, рус. названия из таблицы ДВФУ), `RIDX` форма→индекс (+ алиасы вариантных форм).

### Формат данных (`app_data.json`)
`words[]`: `s` иероглифы · `p` пиньинь с тонами (слоги через пробел) · `ru` · `d` отображение со скобочной
пометой (接(电话)) · `en[]` · `rad` ключ · `hsk` 1–6 · `pos[]` · `cl[]` счётные · `f` частотность ·
`k[]` уроки Кондрашевского · `alt[]` другие чтения · `ra:1` авто-перевод (можно перепроверить) ·
`ex=[zh, pinyin, ru]` пример (505 шт., только уроки 1–30, лексика строго из пройденных уроков).
`chars{}`: `[число черт, "названия черт через пробел", "компоненты через пробел"?]`.
Итого: 5472 слова, 1828 иероглифов, 100% русский перевод, 100% порядок черт.

## Правила данных (выстраданные)
- Русские переводы: auto (json_hsk) + ~2400 ручных. Ловушки CC-CEDICT: первый глосс часто фамилия/топоним
  (树林 ≠ город, 番茄 = помидор, 大都 = большей частью). Новые слова переводить по смыслу HSK.
- Пиньинь: односложные слова сверять с pypinyin; источник любит фамильные чтения (都 Dū→dōu, 藏 zàng→cáng).
  Не «исправлять» намеренное: 还 huán в 还你, 弹 tán, 所长 cháng, 好学 hào xué, нейтральные тоны péngyou.
- Примеры к урокам: только иероглифы, пройденные к этому уроку (накопительно).
