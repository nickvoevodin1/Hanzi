# Иероглифы по урокам — Кондрашевский, «Практический курс китайского языка», том 1

> Все новые слова (生词) всех 30 уроков, разбитые по урокам. Для каждого слова — иероглиф, пиньинь и перевод. Для каждого иероглифа дополнительно дан порядок черт (笔顺) и количество черт.
> Уроки 1–12 — вводный фонетический курс, 13–30 — основной курс (18, 24, 30 — уроки-повторения). Порядок черт сгенерирован по стандарту 笔顺.

## Как читать порядок черт (笔顺)

Черты записаны стандартными названиями (китайская система 笔顺). Базовые:

- **横** héng — горизонтальная (一)
- **竖** shù — вертикальная (丨)
- **撇** piě — откидная влево (丿)
- **捺** nà — откидная вправо (㇏)
- **点** diǎn — точка (丶)
- **提** tí — восходящая (㇀)

Составные содержат: **折** zhé — слом, **钩** gōu — крюк, **弯** wān — изгиб (например **横折钩** héngzhégōu, **竖弯钩** shùwāngōu, **撇折** piězhé). «Черт» в таблице — общее количество черт в иероглифе.
