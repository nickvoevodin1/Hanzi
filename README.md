# 朱 · Тренажёр иероглифов (PWA)

Иероглифы по учебнику **Кондрашевского, том 1 (уроки 1–30)**: ключи, иероглифы, пиньинь, перевод,
прописи и подготовка к проверочным. Интервальное повторение FSRS-5, работает без интернета.
HSK 1–6 (5472 слова) — дополнительно, в словаре.

## Что внутри
- **Сегодня** — одна кнопка «Учить»: повторения и новые слова по урокам по порядку учебника. Перед первым
  словом с новым ключом сначала показывается сам ключ. Ниже — ближайшая проверочная и «догнать группу»:
  сколько слов осталось до текущего урока группы.
- **Уроки 1–30** — слова урока, новые иероглифы урока с разбором, новые ключи, «Учить урок», прописи
  урока, прослушивание, выбор режима (авто, 汉字 → перевод, перевод → 汉字, написать, на слух, тоны, пиньинь).
- **Разбор любого иероглифа по тапу**: ключ (№ по таблице 214, название из таблицы ДВФУ), из каких частей
  состоит, где смысловая и где звуковая часть, черты, слова с этим знаком.
- **Проверочные** — полный цикл подготовки. Для каждого блока: разбор → слова → тоны → порядок слов →
  перевод на слух → перевод с русского → диктант. Каждые 3 блока повторение, затем пробная и финальная
  проверка. Ошибки возвращаются, пока не ответишь верно. Есть настоящая проверочная по уроку 18 и
  автоматическая тренировка по каждому уроку из примеров учебника. Новые проверочные, диктанты и
  контрольные добавляются по списку заданий: пришли его Claude.
- **Ключи** — 214 ключей; учить ключи из пройденных уроков или все 214.
- **Словарь** — поиск по иероглифам, пиньиню (можно без тонов) и по-русски, списки HSK 1–6.
- **Режим «Авто»** сам подбирает задание по тому, насколько прочно помнишь слово: сначала узнавание,
  потом вспомнить иероглиф и тоны, потом написать иероглиф по чертам и диктант на слух.
- Настройки: урок группы, новых слов в день, голос, сброс.

Клавиатура на ноутбуке: Пробел/Enter — показать/дальше, 1/← — не помню, 2/→ — помню, 1–4 — варианты,
Backspace — отменить последнюю оценку.

## Публикация (GitHub Pages)
Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Сайт — файлы в корне репозитория.
На телефоне: меню браузера → «На экран Домой». Прогресс хранится на устройстве (у каждого браузера свой).

## Озвучка голосом носителя (по желанию)
По умолчанию — голос устройства. Для нейроголоса: `pip install edge-tts`, затем `python make_audio.py`
рядом с `index.html`, и загрузить папку `audio/` в репозиторий — приложение подхватит её само.

## Для разработки
Исходники — `src/`, сборка — `python3 tools/build.py`, тесты — `npm install && npm test`.
Подробности — в `CLAUDE.md`.
