# 朱 · Тренажёр иероглифов (PWA)

Изучение китайских иероглифов: **Кондрашевский, том 1 (все 30 уроков)** + **HSK 3.0 (уровни 1–6)**.
5472 слова, все с русским переводом. Прописи по чертам (офлайн), пиньинь с тоновыми цветами,
озвучка, интервальное повторение FSRS-5, статистика. Работает без интернета.

## Файлы (загрузи В КОРЕНЬ репозитория ВСЕ)
- `index.html` — приложение (данные слов встроены)
- `hanzi-data.json` — графика черт для 1828 иероглифов (нужна для офлайн-прописей)
- `manifest.json`, `service-worker.js` — оболочка PWA (офлайн + установка)
- `icon-192.png`, `icon-512.png`, `icon-maskable.png` — иконки

## Публикация на GitHub Pages
1. Создай репозиторий (например `hanzi`), залей **все файлы из этой папки** в корень.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/root`. Сохрани.
3. Через ~минуту откроется `https://<ник>.github.io/hanzi/`.
4. На телефоне: меню браузера → **«На экран Домой» / «Установить приложение»**.
   На ноутбуке (Chrome): значок установки в адресной строке.

После установки всё работает офлайн, прогресс хранится на устройстве.

## Озвучка голосом носителя (по желанию, очень рекомендую)
По умолчанию работает системный синтез. Чтобы получить **естественный нейроголос носителя**:
1. На компьютере: `pip install edge-tts`
2. Положи `make_audio.py` рядом с `index.html` и запусти `python make_audio.py`
   (≈5800 файлов, займёт ~15–30 минут; повторный запуск докачивает недостающее).
3. Загрузи появившуюся папку `audio/` в репозиторий.
Приложение само найдёт пак и будет играть его (и слова, и примеры); без пака — синтез.
Мужской голос: `python make_audio.py --voice zh-CN-YunxiNeural`. Список: `--list-voices`.

## Что внутри
- **Словарь**: по 30 урокам Кондрашевского, по HSK 1–6, **таблица 214 ключей** (русские названия — из таблицы ДВФУ; тап по ключу → значение, варианты написания, все слова с ним, прописи ключа и тренировка), поиск. С карточки слова ключ кликабелен.
- **Карточка**: иероглиф, пиньинь (тоновые цвета), перевод, радикал, **состав иероглифа** (好 = 女 + 子), счётное слово, порядок черт по каждому знаку, частотность, теги, озвучка, **пример предложения** (для слов Кондрашевского — 505 примеров строго на лексике текущего и предыдущих уроков, с пиньинем и переводом).
- **Режимы учёбы** (FSRS-5): смешанный, узнавание, выбор перевода, «вспомни иероглиф», ввод пиньиня, на слух, **тоны**, **диктант** (письмо на слух).
- **Введение новых слов**: перед первым опросом слово показывается карточкой (пиньинь, перевод, черты, пример, озвучка) — и только потом спрашивается.
- **Умный порядок новых слов**: сначала уроки Кондрашевского по порядку (урок 1 → 30), затем HSK по уровню и частотности.
- **Отмена последней оценки** (↩ в сессии или Backspace) — от случайных нажатий.
- **Клавиатура на ноутбуке**: Space/Enter — показать ответ, 1–4 — оценка, Backspace — отмена.
- **Лимит карточек за сессию** (по умолчанию 20, настраивается; изучение урока не ограничивается).
- **Слово дня** на главной, сводка «сегодня: N повторено, M новых», напоминание о резервной копии раз в неделю.
- Режимы «**Вспомнить слово**» (перевод → назвать 汉字) и «**Набор иероглифа**» (печать с китайской раскладки — для осени за ноутбуком).
- Фильтр «только новые» в списке урока, кнопка «копировать» на карточке, прогноз повторений на 2 дня в статистике.
- **Разбор ошибок** после сессии + кнопка «Повторить ошибки»; в статистике — список **трудных слов** (3+ провала) с отработкой.
- **Выбор области**: учить весь словарь / только повторение / конкретный HSK / конкретный урок Кондрашевского (1–30) — любым режимом.
- **Прописи**: письмо по чертам с проверкой порядка (офлайн).
- **Статистика**: серия дней, изучается/закреплено, график 14 дней, прогресс по наборам.
- Настройки: новых слов в день, целевое удержание, выбор голоса, автопроизношение, сброс прогресса, экспорт/импорт.

## Надёжность прогресса
Прогресс хранится по **стабильным ключам-иероглифам** (не по номерам), поэтому будущие добавления слов
(HSK 6, том 2) не собьют вашу статистику. Старый формат мигрирует автоматически при первом запуске.

## О переводах
- Кондрашевский (696 слов) — выверенный русский из учебника.
- ~950 слов HSK — перевод из открытого словаря для русскоязычных (в карточке помечены «можно перепроверить»).
- Остальные HSK 1–3 — переведены вручную по значению.
Английское значение сохранено вторым полем на карточке для сверки.

## Замечания
- В **превью claude.ai** прогресс не сохраняется между перезагрузками, а прописи могут не грузить
  графику (песочница). После публикации/установки — всё работает и сохраняется.
- Озвучка — системный голос zh-CN (iPhone/Mac — Ting-Ting; Chrome — Google 普通话). Кнопка 🔊 сверху проверяет голос.
