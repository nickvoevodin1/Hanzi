# 朱 · Тренажёр иероглифов (PWA)

Иероглифы по учебнику **Кондрашевского, том 1 (уроки 1–30)** в игровом формате: ключи, иероглифы, пиньинь,
перевод, разбор на ключи, перевод предложений и пробные контрольные. Под игрой — интервальное повторение FSRS-5.
Работает без интернета. HSK 1–6 — дополнительно, в словаре. Слова и слоги озвучены **записями носителей** — тоны слышны чётко.

## Что внутри
- **Путь** (главная): серия 🔥, заморозки ❄️, кольцо дневной цели XP, карточка «Семестр» (выучено, закреплено,
  дней до конца, нужный темп, ближайшая контрольная, прогноз), план дня и кнопка «Урок дня».
  Ниже — дорожка: раздел «Ключи» (все 214, 11 юнитов; после каждых 7 ключей — их пропись) и «Уроки 1–30» (юнит на урок:
  новые слова по 7, иероглифы урока — разбор на ключи и пропись, предложения, повторение, проверочная, мини-контрольная),
  контрольные из настроек — «босс»-узлы. Узел «треснул» — слова пора повторить. Корона юнита — из памяти.
  «Перепрыгнуть» — тест по закрытым юнитам: 80% — юниты засчитаны.
- **Урок** — 10–15 заданий разных типов: выбор перевода, выбор иероглифов, на слух, пиньинь, тоны (с графиком тона),
  «Пары», «Собери предложение», «Разбери иероглиф» (части, тип, фонетик, ключ), «Что за ключ?», прописи. Ошибка возвращает
  задание в конец урока. В конце — XP, точность, время.
- **Прописи иероглифов и ключей**: сначала порядок черт — черта за чертой, с названием каждой черты по таблице черт курса
  и составом знака по ключам; потом обвести по контуру; позже в уроке — написать по памяти (по пиньиню и значению).
  Ключи — в формах, как они пишутся в иероглифах (人 и 亻, 言 и 讠, 水 и 氵). Ошибся — в конце урока обведёшь ещё раз,
  а интервальное повторение вернёт знак раньше. В плане дня — «Прописи — 6».
- **Состав по ключам** у каждого нового слова виден сразу: «谢 = 讠 (ключ 149 «речь») + 射 (фонетик shè)», тип и ключ.
- **Семестровый план**: квота новых слов на день считается так, чтобы к дате «новые слова до» (по умолчанию
  28.12) пройти уроки до 30-го; поездки к родителям и каникулы учитываются, перед контрольной — фокус-неделя.
  Кнопка «Я сегодня уезжаю» — в этот день только повторения. Ключи — 10 новых в день, пока не введены все 214.
- **Повторение**: всё к сроку, разбор на ключи (на бумаге — потом сверка и оценка), «Разбери иероглиф»,
  «Тоны на слух» (слог в записи носителя → какой тон; при ошибке — «сравни» все четыре тона),
  перевод предложений (RU→中 и 中→RU, целиком или отрывками), свои предложения от преподавателя,
  пробная контрольная (5 слов + 10 предложений, таймер, прогноз оценки), проверочные, карточки-классика
  (4 кнопки оценки), ключи-справочник, прописи иероглифов и ключей, свободные прописи, трудные слова.
- Прописи работают и без интернета: библиотека hanzi-writer (MIT) и графика черт лежат в приложении.
- **Словарь**: поиск по иероглифам, пиньиню и по-русски, уроки 1–30, ключи, черты, HSK 1–6.
  Тап по любому иероглифу — разбор по «Пособию по иероглифике» Кондрашевского: тип (изобразительный / условный
  знак / идеограмма / фоноидеограмма), ключ, фонетик и его чтения, черты, слова с этим знаком.
- **Прогресс**: календарь занятий, XP и точность по неделям, слова по состояниям, короны уроков,
  готовность к контрольной, достижения.
- **Настройки**: семестр (урок группы, даты, каникулы, поездки, контрольные), цель XP, звуки, вибрация,
  таймер и шкала оценок пробной, озвучка (живые записи вкл/выкл, «Скачать» все записи для офлайна ≈6 МБ), сброс.

Если свернуть приложение, а телефон выгрузит его из памяти, при возвращении откроется тот же экран и тот же урок
(в течение 12 часов).

Клавиатура на ноутбуке: Пробел/Enter — показать/дальше, 1–4 — варианты ответа и оценки, ←/→ — «не помню»/«помню»,
Backspace — отменить последнюю оценку в карточках.

## Публикация (GitHub Pages)
Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Сайт — файлы в корне репозитория.
На телефоне: меню браузера → «На экран Домой». Прогресс хранится на устройстве (у каждого браузера свой).

## Озвучка
Слова и слоги — записи носителей из открытой базы [audio-cmn](https://github.com/hugolpz/audio-cmn) (слоги — Chen Wang,
слова — Yue Tan; CC BY-SA, подробности в `audio/README.md`). Предложения и слова без записи — голос устройства.
Ещё вариант для предложений (по желанию): Для нейроголоса: `pip install edge-tts`, затем `python make_audio.py`
рядом с `index.html`, и загрузить папку `audio/` в репозиторий — приложение подхватит её само.

## Для разработки
Исходники — `src/` (интерфейс — `src/template.html` + модули `src/js/*.js`), сборка — `python3 tools/build.py`,
тесты — `npm install && npm test`. Подробности — в `CLAUDE.md`.
